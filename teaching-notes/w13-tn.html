Week 13 Teacher Notes

Student Expectations At Home

  • Complete the tasks for the week (in addition to time given in class) This includes creating their own GitHub repository for their portal page and hosting their portal on GitHub pages.
  • In an HTML page on their portal site, they will write a detailed report about their experiences with each of their websites they were apart of.

Class Lesson Suggestions

  • Review GitHub and GitHub Pages as needed
    This week everyone needs to host their portal pages on GitHub, review repository creation and GitHub page hosting as necessary
  • Look back on all the ICE challenges
    While demonstrating hosting the portal page, encourage everyone to have all their ice challenges linked on their portal page. Look back at all the projects they have completed.
  • Javascript taste test This is a good week to demonstrate some uses of javascript to preview what they will be learning in the next class. I suggest using javascript fetch to dynamically put the same header and footer on all the pages of the portal site.

Week 13 Goals

  • Reflect on the client/dev project
  • Publish portfolio of class work on GitHub pages, complete any missing work.
  • Look ahead to javascript and cse131
