Week 09 Teacher Notes

Student Expectations At Home

  • Read and watch information on how to recognize truth online. Take the quiz.
  • Plan, design, and create content for a personal site

Class Lesson Suggestions

  • Guided Practice:
    Use Portal Page for Demonstrating CSS grid layout method Demonstrate how to layout elements on the portal page using grid display. Show examples of vertical, horizontal, and both.
  • Guided Practice:
    Use Portal Page to Demonstrate responsive design and media queries. Show how image widths can be percentages to respond to screen size.
  • Guided Practice:
    Use Portal Page to Demonstrate how to use the same CSS to style multiple pages.
  • Class Discussion:
    Have a short discussion truth and how to recognize legitimate and trustworthy sources online.

Week 04 Goals

  • Learn about css grid and practice using it for page layout.
  • Play games to practice Grid properties.
  • Learn basic responsive design methods using media queries.
  • Practice putting together a web page by following a tutorial.
  • Think about truth online and what is truth.
