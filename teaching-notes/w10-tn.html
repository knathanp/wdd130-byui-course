Week 10 Teacher Notes

Student Expectations At Home

  • Complete the tasks for the week (in addition to time given in class)

Class Lesson Suggestions

  • Getting the client/dev project started
    • Prepare for the client/dev project by using the client_dev_wdd.py script. You will need to edit the script to read a file with your class list. (It is very important that you only add students that have been actively attending class, if a student is on your roll who has not been participating in class you should not include them.) The script will give a new random grouping each time you run it, so run it until you are satisfied with the groupings and then print print out the groups. It is helpful if you print a copy of the groups for each person.
    • To introduce the project as a simulation of workforce product management, let students know they will all be hiring a development team to create the site that they planned. Then give them a copy of the groups. Have them highlight their names on their copy. Each student should appear exactly 4 times. Once as a client and a lead developer, and twice as a junior developer. Stress the importance of communication.
    • Describe the roles each student will have for the project and their expectations in that role. Project Requirements
    • GitHub will be a critical tool for this project to manage files and to host each website. Each lead developer will need to create a repository for their client. Have everyone log into their GitHub account or create an account if they do not have one. Everyone should write down their GitHub username to share with their groups. Then demonstrate how to create a new repository (call it wdd130-[clientlastname]). Encourage students to manage their repository with the GitHub Desktop App, and to edit their files with the Visual Studio Code editor. Demonstrate how to create a basic index.html page and commit and push it to the repository. Demonstrate how to host their files with GitHub pages and find the URL for their site. Also demonstrate how to add contributors to their repository using GitHub usernames.
    • Give students time in class to exchange contact information and "hire" their lead developer, create their client's repository, and share their GitHub usernames with the other groups they are apart of.

Week 10 Goals

  • All students assigned to groups and understand the details of the final project.
  • Understand the need for a tool like GitHub
  • Understand basic web hosting
