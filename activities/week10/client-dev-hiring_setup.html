Client / Developer Team Project

The final for this course will be a team project where you will develop each others' personal sites. Everyone will have an opportunity to practice being a client who hires a development team, and everyone will have a chance to lead a development team in building a site for a client. You will be using GitHub to manage your sites and publish them to the web.

Project Overview

Each student will have 3 roles:

  1. Client: As a client, your are responsible for the site plan and content creation of your personal website. You will hire 2 other students as your dev team to develop and code your site (a lead developer and a junior developer). You will communicate with the lead developer to make sure your site is completed on time.
  2. Lead Developer: As a lead developer you will be responsible for creating the client's website. Your main job is to code the home page of the client's site. You will manage one other student (the junior dev) on your team who will code the two child pages. You will create and manage the GitHub repository where the client's website will be stored. You will need to give the other student access to the repository. You will be responsible for publishing the site online using GitHub pages. You will share the published website with the client on a regular basis.
  3. Junior Developer: As a junior developer you will be a member of one other dev team. You will be responsible for creating the two child pages for the client. You will need to communicate with your lead developer to know which pages to work on and how to access the site.

This week's tasks:

  1. Client Tasks

    1. "Hire" a dev team by contacting the lead developer of your assigned dev team and decided on your preferred communication method.
    2. Send the lead developer your site plan, which must include all content and wireframes.

  2. Lead Developer Tasks

    1. Contact your client and exchange communication information.
    2. Create a new GitHub repository for your client by following these steps:
      1. Create a new folder on your computer called wdd130-clientlastname.
      2. Open this folder in VS Code.
      3. Create a file called index.html with a basic HTML structure. Write the client's name as an <h1> in the body.
      4. Click on the "Source Control" button in VS Code and click "Publish to GitHub". Make sure you choose "Public" as the repository type.
      5. Enable GitHub Pages: Once the repository is created, open it on GitHub and click on the "Settings" tab. Click on the "Pages" section in the left sidebar. Under "Build and deployment", select the "main" branch in the branch dropdown. This will publish your site on GitHub Pages.
      6. Back on the "<>Code" tab, edit the "About" section on the right side of the page and add the URL for the published site.
    3. Collect the GitHub username from your assigned junior developer and add them to the repository.
      1. Click on the "Settings" tab in the repository.
      2. Click on "Collaborators" in the left sidebar.
      3. Under "Manage Access", add the junior developer's GitHub username.
    4. You may begin creating the HTML for the home page and adding the content given to you by the client in their site plan. The completed HTML (including images and text) will be the main focus for next week.

  3. Junior Developer tasks

    1. Contact your lead developer and give them your GitHub username.
    2. Request access to the client repository.
    3. Clone the client repository to your computer by following these steps:
      1. On Github, click on the green "<> Code" button and copy the URL.
      2. Open a new VS Code window, click on the "Source Control" button, and click on "Clone Repository". Paste the URL and choose a local folder to clone the repository to. Make sure this folder is NOT inside your existing wdd130 folder. It should be a completely separate folder!
    4. Create two html files for your assigned pages using an appropriate name for each page. In each html file, create a basic HTML outline. You will be adding more HTML and content to follow the site plan next week.
    5. Push your changes to GitHub using the "Source Control" tab in VS Code.

  4. Submit

    Use this template to submit a short report of your progress for this week's task. Be sure to list your lead developer who you hired to develop your site, the junior developer you are in charge of, and lead developer that you work for.
