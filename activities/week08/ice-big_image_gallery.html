In Class Exercise (ICE) Challenge: Big Image Gallery

Overview

  • Task: Create thumbnail images of an appropriate file size.
  • Purpose: Try using a photo editor to change image file size.
  • Expectation: ICE Challenges are designed to be completed in less than an hour. See what you can complete in an hour and then submit it.
  • Extra Credit Opportunity: You can receive bonus points for adding cool, creative, clever features to enhance the challenge

Instructions

  1. Open the files

    • Download the starter files

      Start by downloading the zip file: Gallery and unzipping it and saving the gallery folder in your ice folder

    • Open in VS Code

      Open the gallery folder in VS Code, then locate gallery.html and open to edit.

  2. Test it out

    • Open in a browser

      Test the gallery.html file by opening it in a browser like Chrome. Hold the shift key and click the browser's refresh button. What do you notice about how the images load?

  3. Optimize the images

    • Create smaller thumbnail images

      1. Change the image size of the big images using a photo editor like Photoshop (Adobe Express is available to all byui students) or an online editor like Photopea or Squoosh. The size of the thumbnail should match the size the image is displayed at on the gallery.html page. (Use your browser's developer tools to figure out what size this is).
      2. Then save the smaller thumbnail files to the images/small folder.

    • Shrink the file size

      Optimize the big images using the same photo editor. Maintain the dimensions of the files (1950px x 2915px), but try to shrink the number of bytes it takes to store the images. Using a different file type is acceptable (ie. png->jpg). Then overwrite the images in the big folder with the optimized images and update the links.

  4. Update the gallery

    • Use the thumbnails

      Change the src attribute of each image to point to the small thumbnail versions of the images. Keep the link pointing to the big images. The goal is that when you click on the thumbnail image on the gallery.html page, it opens the big image on a new page.

  5. Submit

    Push your changes to Github. Then please submit the following:

    1. A screenshot of Windows Explorer or Mac Finder showing your small folder contents. Change your view to show the file sizes before taking the screenshot.
    2. Create a submission comment with the URL to the page you completed for this ICE challenge.
