1. Which of the following is a block-level element?
A) <span>
B) <a>
C) <div>
D) <img>
Answer: C

2. What is the default behavior of block-level elements?
A) They appear side by side.
B) They float to the right.
C) They stretch to take up full width.
D) They are hidden.
Answer: C

3. Which display value allows setting width and height while aligning inline?
A) block
B) inline
C) inline-block
D) none
Answer: C

4. How do you center an inline element's content?
A) margin: 0 auto
B) text-align: center
C) display: flex
D) position: absolute
Answer: B

5. What is the primary function of padding?
A) Adds space outside the border
B) Changes font size
C) Adds space inside the element’s border
D) Alters width
Answer: C

6. What separates padding from margin in the box model?
A) Spacing
B) Border
C) Content
D) Container
Answer: B

7. Which shorthand correctly sets padding for top, right, bottom, and left?
A) padding: 5px 15px
B) padding: 10px 20px 30px 40px
C) padding: top right bottom left
D) padding: 20px
Answer: B

8. How do you include padding and border in an element’s total width?
A) display: inline
B) padding-box: true
C) box-sizing: border-box
D) border-collapse: collapse
Answer: C

9. How is a class selector written in CSS?
A) #classname
B) .classname
C) classname
D) @classname
Answer: B

10. What is true about id selectors?
A) Multiple elements can share an id
B) They start with a dot in CSS
C) Only one element should have a given id
D) They override class selectors
Answer: C

11. Why might you use multiple class names on one element?
A) To confuse the browser
B) To avoid using CSS
C) To apply multiple styles

12. Which of the following selectors has the highest specificity?
A) element
