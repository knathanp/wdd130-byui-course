Client / Developer Team Project - HTML

Every client should have sent their site plan to their lead developer and every lead developer should have a github account created for their client's site. This week you will be focusing on creating the HTML pages for your sites.

This week's tasks:

  1. Client Tasks

    • If there are any changes you would like to make to your site plan, send the changes to the lead developer right away.
    • Ask the lead developer for the URL of your site.

  2. Lead Developer Tasks

    • Convert the client homepage wireframe into an HTML page. This includes all of the written and image content for the homepage.
    • Publish the changes to GitHub.
    • Check the URL of site to see if the changes were applied.
    • Submit the URL of the site to the client and tell them what you changed.
    • Share the site plan with the junior developer.
    • Let the junior developer know when you finish the HTML homepage so they can use it as a template for the two child pages.

  3. Junior Developer tasks

    • Start with the HTML of the homepage (ask the lead when it is ready). Use this as the starting point for the two subpages.
    • Create the HTML content for the child pages based on the client's site plan.
    • Let the lead developer know when the HTML is complete.

  4. Submit

    Use this template to submit a short report of your progress for this week's task.


Project Overview

Each student will have 3 roles:

  1. Client: As a client, your are responsible for the site plan and content creation of your personal website. You will hire 2 other students as your dev team to develop and code your site (a lead developer and a junior developer). You will communicate with the lead developer to make sure your site is completed on time.
  2. Lead Developer: As a lead developer you will be responsible creating the client's website. Your main job is to code the home page of the client's site. You will manage one other student (the junior dev) on your team who will code the two child pages. You will create and manage the GitHub repository where the client's website will be stored. You will need to give the other student access to the repository. You will be responsible for publishing the site online using GitHub pages. You will share the published website with the client on a regular basis.
  3. Junior Developer: As a junior developer you will be a member of one other dev team. You will be responsible for creating the two child pages for the client. You will need to communicate with your lead developer to know which pages to work on and how to access the site.
