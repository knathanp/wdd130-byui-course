W01: Editor Installation

Overview

  • Task: Setup your code editor.
  • Purpose: Efficient and effective app for editing your web page code.

Background

Browsers take HTML files and display them as web pages. You can create an HTML file in a simple plain text editor, but it is a much more enjoyable experience to use a smarter editor. Some code editors include lots of helpful features that make writing HTML easier. Choose an editor that recognizes HTML code, helps you write it, and colors it to make it easier to read.

The suggested code editor for this class is Visual Studio Code (VSCode).
