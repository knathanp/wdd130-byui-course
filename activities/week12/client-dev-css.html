Client / Developer Team Project - CSS

Every lead developer should have a good HTML structure for their client's site. This week you will be focusing on styling with CSS and focusing on the visual details.

This week's tasks:

  1. Client Tasks

    • Respond to any requests for more images or content from your developer, or any other questions they might have.
    • Look at the published page in the current HTML form and check that the content has been put in correctly with no typos.
    • Give your developer feedback as needed

  2. Lead Developer Tasks

    • Style the html with css to match the wireframe, colors, fonts and images and make it look nice.
    • Publish the changes to GitHub
    • Check the URL of site to see if the changes were applied
    • Let the client know the site has been updated and ask for feedback.
    • Coordinate with the Jr. Developers to use the same css style sheet on all three pages.

  3. Junior Developer tasks

    • Coordinate with the Lead developers to use the same css style sheet on your page.
    • Add styles as needed. Be careful to fetch/pull changes from GitHub before making your own changes.
    • Let the lead developer know when your page is complete.

  4. Submit

    Submit a short report of your progress for this week's tasks. Be sure to include the 4 URL's of the sites you are involved in.


Project Overview

Each student will have 3 roles:

  1. Client: As a client, your are responsible for the site plan and content creation of your personal website. You will hire 3 other students as your dev team to develop and code your site. You will communicate with the lead developer to make sure your site is completed on time.
  2. Lead Developer: As a lead developer you will be responsible creating the client's website. Your main job is to code the home page of the client's site. You will manage two other students on your team who will code the two child pages. You will create and manage the GitHub repository where the client's website will be stored. You will need to give the other two students access to the repository (do not give the client access to the repository). You will be responsible for publishing the site online using GitHub pages. You will share the published website with the client on a regular basis.
  3. Junior Developer: As a junior developer you will be a member of two other dev teams. You will be responsible for creating a child page for each dev team. You will need to communicate with your lead developers to know which pages to work on and how to access the sites.
